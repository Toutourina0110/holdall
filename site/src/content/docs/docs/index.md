Holdall is a self-hosted personal toolbox: notes, tasks, a synced calendar, video downloads, a file converter and a file manager. It runs on your desktop or your own server, with your data in one folder you control.

## Where to start

| You want to | Read |
|---|---|
| Understand what Holdall is and how it stores data | [Overview](/docs/overview/) |
| Run Holdall on a server with Docker or Coolify | [Settings](/docs/install/configuration/), then [Docker](/docs/install/docker/) or [Coolify](/docs/install/coolify/) |
| Use Holdall on your own computer | [Desktop app](/docs/desktop/install/) |
| Learn each screen | [User guide](/docs/guide/first-steps/) |
| Build a plugin or a theme | [Write plugins](/docs/plugins/overview/) |
| Work on Holdall itself | [Development](/docs/contributing/development/) |

You can also [try the demo](https://demo.holdall.site) without installing anything.
