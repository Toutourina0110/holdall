---
title: Customize
description: Move, hide and restyle elements, pick or build a theme, and save your layout.
---

Every person has their own layout and theme. Changes never affect other accounts.

## Customize mode

Click **Customize** in the top bar.

- Drag the grip to reorder elements, in the side bar or on **Today**.
- Use the eye to hide an element or show it again.
- Select an element to change its style: **label**, **icon**, **color**, **background**, **size**, **spacing** and **corners**. **Reset this element** undoes your changes to it.

**Save layout** keeps your changes. **Cancel** drops them. **Reset everything** goes back to the default layout.

## Theme

Open **Settings, Appearance**.

- **Theme**: **Follow the system**, **Light**, **Dark** or **Custom**. Changes preview on the whole app immediately; **Save theme** keeps them.
- **Theme editor** (with **Custom**): pick a base (light or dark), then change **colors**, **corners**, **spacing**, **text sizes** and **density**. **Contrast check** tells you if any text and background pair falls below the WCAG AA contrast ratio of 4.5:1.
- **Export theme** saves it to a file; **Import theme** loads one.
- **Installed themes** lists theme plugins installed by the admin. **Use this theme** applies one.

## Save and share a layout

Open **Settings, Layout**.

- **Export layout and theme** saves both to one file.
- **Import layout and theme** loads such a file. An invalid file changes nothing.
- **Reset layout** goes back to the default.
